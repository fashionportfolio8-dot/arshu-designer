# ARSHU DESIGNER

Luxury Indo-Western Fashion Portfolio — Where Indian Craft Meets Contemporary Fashion.

A cinematic, editorial Next.js experience with interactive 3D storytelling, fashion galleries, and a future-ready runway showcase.

## Stack

- Next.js + TypeScript
- Tailwind CSS
- React Three Fiber + Drei
- GSAP, Framer Motion, and Lenis
- Supabase integration planned for the CMS phase

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.
